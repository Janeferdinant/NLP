# Archive: legacy site files

Everything in this folder is **unrelated to the SMS spam classifier**. These files were in the repository root before it was restructured as an NLP project. They were moved here with `git mv` so that the file history is kept.

## What is here

| Files | What they are |
|---|---|
| 10 `.jpeg` images | AI-generated illustrations with portfolio-style titles: Bank Note Authentication, Housing Price Prediction, Loan Prediction, Mall Customer Segmentation, Movie Recommender System, Stock Market Analysis and Prediction, Twitter Sentiment Analysis, future, gan, pink. The repository does not record where the images came from. |
| `stylesheet.css` | The W3.CSS 4.15 style sheet from w3schools.com (third-party). Nothing in this project uses it. |
| `jekyll-gh-pages.yml` | The GitHub Actions workflow that GitHub suggests for Jekyll sites. Its runs on `main` failed (2026-10-13 and 2026-10-14), so it is kept here, out of `.github/workflows/`. |

**Removed on 2026-10-23 (owner approved):** seven AI-generated tiles titled for Tableau and Power BI dashboards, because this repository contains no such dashboards and the third-party IEEE paper PDF (copyright). They remain in the git history.

## Use in the project

One image, `Twitter Sentiment Analysis.jpeg`, is used as the decorative banner in the top-level README, with alt text that says what it is.

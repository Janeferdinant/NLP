## Changes under test

- Cell 16: removed `input=list` (scikit-learn 1.9.1 raised `InvalidParameterError`, since `input` must be `'content'`, `'file'` or `'filename'`) and renamed the variable that shadowed the builtin `list`.
- Cell 7: `"".join(...)` became `" ".join(...)`, so the last word of one message no longer fuses with the first word of the next in the word clouds. This affects the word clouds only, not the classifier.
- Cell 1: downloads `spam.csv` when it is not next to the notebook (for Colab).
- Cell 20 (new): `joblib.dump` of the fitted vectorizer and model to `model/` (git-ignored).


**0 mismatches out of 1,672.** In a separate check the per-class joint log-likelihoods from the JavaScript code were bit-identical to `MultinomialNB.predict_joint_log_proba` on all 1,672 rows (maximum absolute difference 0.0). The smallest margin between the two class scores was 0.0002, so the parity is exact, not a lucky rounding.
